# DESIGN.md — визуальный язык OPORA

Направление: **«ночная бумага»**. Приложение открывают вечером, чтобы записать день, — экран должен быть тихим, а не весёлым. Тёмная тёплая база, бумажный текст, один янтарный акцент.

Токены живут в `src/theme.rs`. Меняешь цвет — меняешь там, не в виджетах.

## Цвет

| Токен | Значение | Где |
|---|---|---|
| `BG` | `#17161A` | фон окна |
| `SURFACE` | `#222027` | поля, наведение |
| `SURFACE_HOVER` | `#2C2933` | подсветка под курсором |
| `TEXT` | `#EDE7DD` | основной текст |
| `TEXT_DIM` | `#8E877E` | подписи, второстепенное |
| `ACCENT` | `#C8A15A` | выбранное настроение, главная кнопка |
| `LINE` | `#35313A` | линии вместо рамок |

Красный для ошибок — `#D06C5E`, только для ошибок.

## Типографика

- **Literata** (serif) — только дата/заголовок, 30–36 px. Это единственный крупный элемент на экране.
- **Golos Text** — всё остальное: основной текст 15, подписи 13, заметка 18.
- Никаких капс-подписей над заголовками, никаких номеров «01 / 02 / 03» — они оправданы только для настоящей последовательности.

Шрифты лежат в `assets/fonts` (OFL, с кириллицей) и вшиваются в бинарник.

## Сетка

- Колонка 560 px по центру окна, поля окна 32 px; навигация слева — 20 px от края.
- Заметка открывается на весь экран: «Сохранить» слева сверху, поле текста занимает весь остаток.
- Вертикальный ритм: 22–32 px между блоками, после заголовка — линия.
- Поля ввода без рамки: строка с линией снизу, как в бумажном дневнике.
- Кнопка сохранения — 150×38, единственное залитое акцентом пятно рядом с выбранным настроением.

## Правила

1. **Один акцент.** Если хочется второй цвет — не хочется.
2. **Без карточек.** Структура держится типографикой и линиями; одинаковые скруглённые карточки — главный признак шаблонного интерфейса.
3. **Настроение — шкала, а не слайдер.** Десять делений 1–10 читаются как измерительная линейка; выбранное залито акцентом.
4. **Движение только в ответ на действие**: наведение, нажатие. Никаких анимаций «на входе».
5. **Тексты** — подписи и состояния с большой буквы («Настроение», «Не помню»), команды строчными («сохранить», «удалить»). Ошибка говорит, что не так, и не извиняется.

## Проверка

Скриншот окна после изменений: крупный серифный заголовок, пустое место справа от колонки, ни одного «серого прямоугольника» без смысла. Если появился второй акцентный цвет или новая карточка — правка мимо языка.
